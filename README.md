# Pixel 10 Countdown Widget App

This project is a starter Android app for creating compact, time-zone-aware countdown and count-up timers for a home screen widget.

## Prerequisites

- Android Studio Ladybug or newer
- Android SDK 34
- JDK 17
- A Pixel device or emulator

## Build steps

1. Open the repository in Android Studio.
2. Let Gradle sync complete.
3. Select a device or emulator.
4. Run the app (`Run > Run 'app'`).
5. To build an APK:
   - `Build > Build Bundle(s) / APK(s) > Build APK(s)`

## Notes

This is a production-ready starter, not a final polished app. It includes:
- Kotlin + Compose UI
- Room persistence
- time-zone-aware timer logic
- a compact app widget
- timer add/delete workflow
